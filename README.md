# AI & ML Internship - Task 1
## Data Cleaning & Preprocessing

# Objective

The objective of this task is to learn how to clean and prepare raw data for machine learning.

# Dataset

Titanic Dataset

# Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

# Tasks Performed

1. Imported and explored the dataset
2. Checked missing values
3. Checked data types
4. Handled missing values
5. Removed unnecessary columns
6. Converted categorical variables using One-Hot Encoding
7. Standardized numerical features using StandardScaler
8. Detected outliers using boxplots
9. Removed outliers using the IQR method
10. Saved the cleaned dataset
